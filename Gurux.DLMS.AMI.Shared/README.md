# Gurux.DLMS.AMI.Shared

Gurux.DLMS.AMI.Shared provides the shared interfaces and data types used by Gurux DLMS AMI v4, an Advanced Metering Infrastructure application for DLMS/COSEM meters.

Use this package when developing modules or integrations that interact with Gurux DLMS AMI. It is a supporting library, not a standalone application.

## Installation

```bash
dotnet add package Gurux.DLMS.AMI.Shared
```
